# data/

このアプリが質問に答える際に検索対象とする「知識の元データ」を置くディレクトリです。
このプロジェクトはRAG（Retrieval-Augmented Generation、「検索して補強してから回答を生成する」方式のAIチャット）
の仕組みを採用しており、ここに置いたファイルの中身がベクトルDB（[Chroma](https://www.trychroma.com/)、
文章の意味を数値化して検索できるようにするローカルDB）に自動で取り込まれ、回答生成のための検索対象になります。

## 置くべきファイル

- 質問対象にしたい `.pdf` / `.txt` / `.md` / `.docx` / `.csv` / `.xlsx` / `.pptx` / `.html` / `.htm`
  ファイルを直接ここに置きます。
- アプリのサイドバーからファイルをアップロードした場合も、自動的にここへ保存されます。
- `sample.txt` はデモ用のサンプルファイルとして同梱されています。

ファイルを追加・変更・削除したら、アプリのサイドバーの「🔄 data/ を再同期」ボタンを押すか、
CLIで `python ingest.py` を実行すると、差分だけがDB（Chroma）に反映されます
（`ingest.py` が `chroma_db/manifest.json` と比較して差分を検知する仕組みです）。
このファイル・manifest.json・Chromaのチャンク・会話スレッドの関係をER図で整理したものが
[docs/data-model.md](../docs/data-model.md) にあります。

## data/conversations/&lt;会話ID&gt;/

チャットでの質問・回答のやりとり（会話ログ）を自動保存する場所です（`memory.py` が担当）。

- 会話（スレッド）ごとに `<会話ID>/`（8文字のランダムな英数字フォルダ）が作られます。
- 1回の質問・回答につき1つの `.md` ファイルが保存されます（ファイル名は日時＋質問内容の一部）。
- 同じ会話IDの中でだけ、以降の質問の回答材料として検索対象になります（無関係な別の会話とは混ざりません）。
- サイドバーの「🧠 記憶設定」内の「今の会話を記憶として保存する」トグルをOFFにすれば、
  この自動保存自体を止められます。
- このフォルダは実際の会話内容を含むため `.gitignore` で除外されており、Gitには含まれません
  （個人の実データが誤ってリポジトリに残らないようにするためです）。

不要になった会話ログは、フォルダごと削除して `python ingest.py` を実行すればDB側からも削除されます
（詳しくはルートの [README.md](../README.md) の「会話ログ（会話の自動ナレッジ化）の管理」を参照してください）。

## 補足: このデータはどこに送信されるか

`data/` の内容は、埋め込み（検索用の数値化）にローカルのHuggingFaceモデルを使うため、
検索の仕組み自体が外部に送信されることはありません。ただし、回答生成にOllama以外
（Claude/OpenAIのAPI）を使っている場合は、検索でヒットした内容が回答生成のためにそのAPIへ送信されます。
詳しくはルートの [README.md](../README.md) の「セキュリティについて」を参照してください。
